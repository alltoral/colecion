# Banners

Coloque aqui as imagens dos banners. O app procura automaticamente pelo nome do arquivo e, se não encontrar, usa o banner padrão em degradê.

| Página | Nome do arquivo |
|---|---|
| Parede completa | `home.jpg` |
| Wishlist | `wishlist.jpg` |
| Hot Wheels | `hot-wheels.jpg` |
| Matchbox | `matchbox.jpg` |
| Majorette | `majorette.jpg` |
| Maisto | `maisto.jpg` |

Outras marcas seguem o mesmo padrão: nome em minúsculas, sem acento, com hífen no lugar de espaço.

**Formato:** 1920 × 600 px (proporção 16:5), JPG com qualidade em torno de 80%, até 400 KB.

**Área segura:** deixe o conteúdo importante (logo, título) no centro, dentro de 1200 × 450 px. No celular as laterais são cortadas. O app escreve o nome da página por cima, no canto inferior esquerdo, então deixe essa área mais escura e vazia (como nos banners atuais, com o carrinho à direita). Os banners são cortados na proporção 16:6 com foco na parte de baixo da imagem.
